## 0.1.0

First version of the COBOL SDK, implementing spec `v1alpha1`.

### Features

* Annotated copybooks as the declaration: service, prefix and program headers, and per-field descriptions,
  constraints, defaults and secrets.
* `docuconf-cobol generate`: writes the `contract.cue` contract and a COBOL loader program from a copybook, in
  fixed or free format, with `-check` to verify committed output; `docuconf-cobol version`.
* The loader runtime copybooks, run under `docuconf exec`, which validates the environment and files at boot.
* The shared conformance suite, run through `docuconf exec` and the loader.
* The `orders` example, a CronJob-style batch program.
